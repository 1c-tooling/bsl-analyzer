# Конфликт имени метода формы с глобальной функцией (GlobalContextMethodConflict)

В модуле формы нельзя объявлять метод с именем глобальной функции платформы: платформа отклоняет такую форму при компиляции. Диагностика проверяет таблицу имён текущего каталога платформы и сообщает конфликт на имени метода.

```bsl
Функция ПредставлениеПериода(Начало, Конец)
    Возврат Начало;
КонецФункции
```

Переименуйте метод формы. Проверка ограничена модулями форм; одно совпавшее имя само по себе не запрещает объявление в остальных типах модулей.
