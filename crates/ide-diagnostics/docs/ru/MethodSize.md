# Ограничение на размер метода (MethodSize)

## Описание диагностики

Процедуры и функции чрезмерно большого размера сложны для понимания, тестирования и сопровождения. Как правило, метод разрастается из-за того, что разработчик добавляет новую логику прямо в него, вместо того чтобы выделить её в отдельную подпрограмму.

Диагностика сравнивает размер метода с настраиваемым порогом:

- `maxMethodSize`, по умолчанию `200`;
- сообщение выдаётся, когда размер строго больше порога (`размер > maxMethodSize`); размер, равный порогу, не сообщается.

Размер метода — разность номеров строк конца и начала его синтаксического узла: `S = строка(конец) − строка(начало)`. Узел метода начинается с первой аннотации (если она есть) и заканчивается после `КонецПроцедуры` / `КонецФункции`. Это не число строк включительно и не число операторов: однострочный метод имеет размер 0, а аннотации, комментарии и пустые строки внутри узла учитываются. Строки вне узла метода не учитываются.

Например, метод

```bsl
Процедура Тест()
    А = 1;
КонецПроцедуры
```

имеет размер 2: при `maxMethodSize = 1` выдаётся одно сообщение с размером 2, а метод из двух строк (размер 1) при том же пороге не сообщается.

Прежние версии вычитали из размера 4 и не сообщали метод с нулевым результатом, поэтому методы короче пяти строк не сообщались ни при каком пороге. Теперь вычитания нет: для методов размером от 4 вычисленный размер на 4 больше прежнего. Методы, которые сообщались и раньше, получают в сообщении число на 4 больше; методы с размером от `maxMethodSize + 1` до `maxMethodSize + 4`, а также короткие методы, размер которых больше порога, теперь сообщаются впервые.

Рекомендации по рефакторингу объёмных методов:

- Если перед блоком кода хочется написать поясняющий комментарий, этот блок стоит вынести в отдельный метод с говорящим названием.
- Если метод решает несколько подзадач, каждую из них стоит выделить в самостоятельный метод.

## Примеры

Примеры иллюстрируют рефакторинг; комментарий о 200 строках в первом из них сам по себе не делает пример большим методом.

Неправильно:

```bsl
Процедура ОбработатьДокумент(Документ)
    // 200 строк кода: валидация, расчёты, запись, оповещение
    // ...
КонецПроцедуры
```

Правильно:

```bsl
Процедура ОбработатьДокумент(Документ)
    ПроверитьРеквизиты(Документ);
    РассчитатьИтоги(Документ);
    ЗаписатьДокумент(Документ);
    ОповеститьПользователя(Документ);
КонецПроцедуры
```
